# Phase 2: Requirement Analysis Phase

Project: LegalEase - AI Legal Document Assistant

Functional Requirements:
- User Registration & Login with JWT
- Chatbot for legal Q&A using Gemini API
- Document Generator (Rental, NDA, Affidavit)
- PDF Download feature
- Dashboard to view history

Non-Functional Requirements:
- Secure authentication
- Fast response time < 2 sec
- Mobile responsive UI
- Data privacy

Tools Required:
- Frontend: HTML, CSS, JavaScript
- Backend: Python FastAPI
- Database: SQLite
- AI: Google Gemini API
- Deployment: GitHub Pages
- Version Control: GitHub
- IDE: VS Code
