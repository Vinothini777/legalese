# Phase 1: Brainstorming & Ideation Phase

Project: LegalEase - AI Legal Document Assistant

Problem: Common people cannot afford lawyers for simple documents like Rental Agreement, NDA, Affidavit.

Solution: AI based web app to generate legal documents automatically and chatbot to answer legal doubts.

Objective:
- Generate legal documents quickly
- Provide AI legal chatbot
- User friendly interface
- Secure login system

Tech Stack: HTML, CSS, JavaScript, Python FastAPI, SQLite, Google Gemini API, JWT Auth
